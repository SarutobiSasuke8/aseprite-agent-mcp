## 0.2.0 - 2026-10-11

Improvement sweep. Highlights first; every item has a regression test.

- **Tool profiles.** `ASEPRITE_MCP_TOOLS` picks the exposed surface: `core` (default,
  40 tools), `all` (112), module groups or single tool names. Unknown names fail at
  startup, and a renamed tool can no longer silently escape the disabled list.
  `python -m aseprite_mcp.server` now goes through the curated profile.
- **Cast tools.** `draw_pixel_rows`, `derive_mirrored_tag`, `copy_frames_from`,
  `recolor_sprite` and `ase_export_cast_atlas` (several validated masters in one
  Phaser atlas). New batch ops: `pixel_rows`, `copy_cel`, `offset_cel`.
- **Typed contracts.** The contract is a typed parameter, so agents see its schema.
  Rows take `tag` (`direction` kept as an alias), `playback` (forward or pingpong),
  `repeat` and `check_anchor`. Exports carry repeat and yoyo per animation.
- **Exports.** `replace=true` swaps a previous bundle by rename; a directory that is
  not an exported bundle is never replaced. The preview draws one labelled row per
  tag over a checkerboard at a chosen scale. The loader declares one `KEY` constant.
- **Safety.** Saves write a sibling copy and swap it in, so a killed process cannot
  half-write a master. Out-of-range frames are errors instead of silent clamps.
  `add_frame(copy_from)` now really appends (it inserted near the start before).
  `export_onion_skin` and `import_image` no longer overwrite existing files.
  Aseprite no longer inherits the server's stdin. Drawing spans, canvas resize and
  scale, and text size are bounded. Root-relative Windows paths, `CONIN$`,
  `CONOUT$` and superscript `COM`/`LPT` names are rejected.
- **Agent ergonomics.** The batch op vocabulary is generated into tool descriptions;
  layer lookups accept digit strings and list available layers on error; next-step
  hints no longer name disabled tools; `plan_asset_spec` and `validate_asset_spec`
  are disabled with the builder they plan for.
- **Locking.** A busy workspace is retried for `ASEPRITE_MCP_LOCK_WAIT` seconds
  (default 15) without blocking the event loop.
- **Repository.** Ruff in CI with Python 3.10-3.13; a single version source;
  `mcp` instead of `mcp[cli]`; owner-specific distribution patterns moved to an
  untracked file; `docs/TOOLS.md` generated by `scripts/generate_tools_doc.py`;
  process-kill lock tests wait for the OS to release the lock.

## 0.1.0 - local, unreleased - 2026-09-07

- Imported 74 source/test files from the MIT upstream; exact original hashes and
  commit are recorded in UPSTREAM_INVENTORY.json. Original copyright is preserved.
- Added the aseprite-agent-mcp stdio entry point and a curated 109-tool surface.
- Added strict asset contracts, composite RGBA/alpha/palette/anchor checks,
  all-frame nearest-neighbour previews, and atomic edit-plus-preview workflow.
- Added Phaser row-sheet/hash-atlas export with per-frame timing, master reopen,
  decoded pixel comparison, new-directory protection and QA reports.
- Tightened configured roots, traversal/stream/device/template handling, protected
  native masters from export overwrites, bounded new canvases and production QA.
- Treat nonzero Aseprite exit as failure even if a result sentinel was printed.
- Constrained MCP SDK to <2 after reproducing the FastMCP import incompatibility.
- Added MCP stdio proof, negative fixtures, Phaser playback fixture, test coverage,
  install/configuration documentation, provenance and package boundary checks.

This derivative does not claim that the inherited general drawing engine was
written from scratch. No live-bridge source has been incorporated.
