# Privacy and distribution review, 2026-10-11

## Verdict

The reviewed Git history and current source are suitable for publication as this
repository. No private credential, local personal path, private workspace file or
asset of uncertain provenance was found. This is a source and packaging verdict;
Alexei still decides when to make the repository public.

## Scope and evidence

- Reviewed all 3 commits reachable from `main`, including author metadata and
  patch history. Authors use GitHub noreply addresses. Gitleaks 8.30.1 scanned
  all 3 commits, about 919 KB, and reported 0 leaks.
- Searched every reachable commit for Windows and POSIX home paths, personal
  email domains, private-key headers and common token prefixes. No matching
  source file was found. Current-tree search and focused review of
  `docs/VERIFICATION.md`, `docs/UPSTREAM.md`, `examples/phaser/`, tests and
  fixtures found no private context. `scripts/check_distribution.py` itself
  contains generic path-pattern examples, not machine-specific data.
- Reviewed tracked filenames and package archives for `.aseprite`, `.ase`, PNG,
  executables, DLLs, Lua files and unknown art. None is tracked or shipped,
  except `docs/demo/synthetic-robot.gif`, which is generated by
  `scripts/generate_demo.py` from simple drawn rectangles and points. There is
  no third-party art in the demo.
- `uv build` produced a 62-file wheel and a 109-file sdist. The full file lists
  are in [DISTRIBUTION_FILES.md](DISTRIBUTION_FILES.md). The wheel carries
  `LICENSE`, `NOTICE` and `UPSTREAM_INVENTORY.json` under
  `aseprite_mcp/notices/`; the sdist carries all 3 at its root. Neither archive
  contains an Aseprite binary, installer, Lua runtime or Aseprite-owned asset.
  `scripts/check_distribution.py` passed against both archives with its generic
  checks. No owner-specific `.private-patterns` file was supplied in this clone.

## Licence posture and limits

The inherited MCP code is attributed to Brendan Malloy in `README.md`, `NOTICE`,
`LICENSE` and `UPSTREAM_INVENTORY.json`. Aseprite is separate, licensed software.
Users bring their own installation or build it under the Aseprite EULA; this
package invokes their executable through `ASEPRITE_PATH`.

This review cannot prove that future commits, a future release build or a local
Aseprite installation are clean. Re-run the source, history and archive checks on
the exact commit selected for publication. The Aseprite live integration suite
was not run on this host because no Aseprite executable is installed.
