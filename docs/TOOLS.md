## apply_operations (**core**)

Group: `batch`

Apply a list of edit operations to a sprite in one atomic, single-process batch. If any op fails, the whole batch is rolled back, nothing is saved, and the error names the failing op index. dry_run=true checks the list without launching Aseprite (shape only; a missing layer still fails on a real run). Returns a workflow_manifest.v1 with a per-op operations list.

Each operation is {"op": "<name>", "args": {...}}. Ops run in order against the same open sprite, so later ops see earlier ones (add a layer, then draw on it). Coordinates are pixels from the top-left (0,0); frames are 1-based and must exist; layer is a name or 1-based index and defaults to the top layer; durations are milliseconds. '?' marks an optional arg.
- add_layer(name:str, opacity?:int, blend_mode?:str, visible?:bool): new layer on top
- rename_layer(layer:str, new_name:str): rename a layer
- set_layer_visible(layer:str, visible:bool): show or hide a layer
- set_layer_opacity(layer:str, opacity:int): layer opacity 0-255
- remove_layer(layer:str): delete a layer (not the last one)
- add_frame(duration_ms?:int, copy_from?:int): append a frame (copy_from copies an existing frame)
- duplicate_frame(frame:int): insert a copy of a frame after it
- set_frame_duration(frame:int, duration_ms:int): frame duration in milliseconds
- add_tag(name:str, from:int, to:int, direction?:str, color?:color): animation tag over frames from..to (direction forward|reverse|pingpong)
- remove_tag(name:str): delete a tag by name
- set_pixel(layer?:str, frame?:int, x:int, y:int, color:color): one pixel
- draw_line(layer?:str, frame?:int, x1:int, y1:int, x2:int, y2:int, color:color): 1px line between two points
- draw_rectangle(layer?:str, frame?:int, x:int, y:int, width:int, height:int, color:color): rectangle outline
- fill_rectangle(layer?:str, frame?:int, x:int, y:int, width:int, height:int, color:color): filled rectangle
- draw_ellipse(layer?:str, frame?:int, cx:int, cy:int, rx:int, ry:int, color:color): ellipse outline
- fill_ellipse(layer?:str, frame?:int, cx:int, cy:int, rx:int, ry:int, color:color): filled ellipse
- fill_layer(layer?:str, frame?:int, color:color): fill the whole cel
- clear_layer(layer?:str, frame?:int): make the cel fully transparent
- add_slice(name:str, x:int, y:int, width:int, height:int, color?:color): named slice rectangle
- remove_slice(name:str): delete a slice
- replace_color(layer?:str, frame?:int, from:color, to:color, tolerance?:int): swap one colour for another in a cel
- pixel_rows(layer?:str, frame?:int, rows:rows, key:key, x?:int, y?:int, clear?:bool): draw a block of pixel art: rows is a list of strings, key maps each character to a colour; '.' and ' ' are skipped unless key defines them; clear=true erases the cel first; x,y place the top-left
- copy_cel(from_frame:int, to_frame:int, layer?:str, to_layer?:str): copy a layer's cel from one frame to another (to_layer defaults to the same layer)
- offset_cel(layer?:str, frame?:int, dx:int, dy:int): move a cel's pixels by dx,dy (bob, step or shake without redrawing)

```json
{
  "properties": {
    "filename": {
      "title": "Filename",
      "type": "string"
    },
    "operations": {
      "items": {
        "additionalProperties": true,
        "type": "object"
      },
      "title": "Operations",
      "type": "array"
    },
    "dry_run": {
      "default": false,
      "title": "Dry Run",
      "type": "boolean"
    }
  },
  "required": [
    "filename",
    "operations"
  ],
  "title": "apply_operationsArguments",
  "type": "object"
}
```
